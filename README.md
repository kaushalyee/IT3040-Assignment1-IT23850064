This repository contains automated test cases for the SwiftTranslator (Singlish to Sinhala) system using Playwright.  
The project was developed as part of IT3040 – ITPM Assignment 1.

## Technologies Used
- Playwright
- Node.js
- JavaScript

 Project Structure
- tests/ : Playwright test scripts
- testData.js : Test case input data
- playwright.config.js : Playwright configuration
- package.json : Dependencies and scripts

How to Run the Project
 1. Install dependencies

npm install
npx playwright install


2. Run automated tests
npx playwright test

3. View HTML report
npx playwright show-report


Test Coverage-

24 positive functional test cases
10 negative functional test cases
1 UI test case
